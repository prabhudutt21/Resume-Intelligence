# Resume Intelligence

An AI-powered Resume Parser and HR Screening System.

## Features
- PDF Resume Extraction
- Skill and Education Detection
- AI Semantic Matching
- Candidate Ranking
- HR Review and Shortlisting
- Candidate Database
- PDF Report Generation
- Excel Export
- OCR Support

## Technologies
- Python
- Streamlit
- SQLite
- Sentence Transformers
- PyMuPDF
- Pandas

## Run the Project

Install dependencies:

pip install -r requirements.txt

Start the application:

streamlit run app.py
